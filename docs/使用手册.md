# StudyPilot 使用手册

面向最终用户的操作指南。所有操作都可通过 Command Palette（`Ctrl+K`）完成，本文补充各界面的详细按键与流程。

---

## 全局快捷键

| 按键 | 功能 |
|---|---|
| `Ctrl+K` | 打开命令面板（所有功能入口） |
| `Ctrl+C` | 中断当前请求（AI 生成/导入等） |
| `Ctrl+Q` | 退出程序 |
| `Esc` | 关闭面板 / 返回上级 / 退出复习 |
| `PageUp` / `PageDown` | 滚动聊天区或复习区 |
| 鼠标拖选 | 选中聊天内容并复制（需剪贴板工具） |
| 方向键 `↑↓` | 面板、列表、选择题中移动光标 |

> 在 **Home** 页按 `Esc` 或 `Ctrl+C` 会直接退出程序（Home 是顶层页）。

---

## 命令面板（Command Palette）

按 `Ctrl+K` 打开，按分组浏览所有动作：

- **学习**：New Conversation、Review、Review Map、Outline（含 Export）、Materials（笔记浏览器）
- **课程**：Switch Course、New Course、Rename Course、Delete Course、Import Materials
- **会话**：Recent Sessions、Rename Session、Export / Load Conversation
- **设置**：Model（切换模型 / 配置角色）、Budget（查看 / 设置 / 重置费用上限）

面板顶部可输入文字**实时过滤**，输入关键词即可缩小范围。

---

## 课程管理

- **新建课程**：`Ctrl+K` → New Course，输入课程名
- **切换课程**：`Ctrl+K` → Switch Course，选择目标课程
- **重命名 / 删除课程**：`Ctrl+K` → Rename Course / Delete Course
  - 删除课程后，该课程的笔记与学习历史会**移到「Global（全部）」区**（数据保留，不丢），可随时切换回其他课程重新归类
  - 删除有二次确认（Home 页按 `d` 两段式），防止误操作

---

## 导入资料

1. `Ctrl+K` → Import Materials
2. 选择资料文件夹或单个文件

支持格式：Markdown（`.md` / `.txt`）、PDF（`.pdf`）、PPTX（`.pptx`）

> 首次使用 PDF 导入前，请在**解压目录**运行一次安装脚本补齐依赖：
>
> - **Windows**（打开 PowerShell）：
>   ```
>   Set-ExecutionPolicy -Scope Process Bypass
>   scripts\install-deps.ps1
>   ```
> - **Linux / macOS**（在解压目录打开终端）：
>   ```
>   bash scripts/install-deps.sh
>   ```

- 每个文件导入时显示处理进度：解析 → 抽取概念 → 入库
- 导入完成后聊天区显示每个文件抽取出的概念数
- **重复导入同一份资料不会产生重复**（按内容自动去重）
- 导入可随时 `Ctrl+C` 中断

导入时会自动完成：

- 按标题拆分为检索单元
- 抽取知识点（概念）
- 归入当前课程

## 提问

在底部输入框直接输入问题即可。

回答的要点：

- 基于**你导入的笔记**回答，不依赖通用知识
- 关键事实后带编号 `[1]`、`[2]`…——在回答下方对应具体笔记片段（来源）
- 笔记没覆盖的内容会标注「（笔记外补充）」
- 如果问题与当前课程无关，AI 会引导回课程主题

**继续追问**：直接输入下一条问题即可，对话会持续（上下文保留）。

## 复习（Review）

复习分两阶段：**闪卡暖场** → **正式出题**。

### 阶段一：Flashcard Warm-up（闪卡）

| 按键 | 功能 |
|---|---|
| `Space` | 翻开当前卡片（显示答案） |
| `1` / `2` / `3` | 自评：会了 / 模糊 / 不会（需先 Space 翻开） |
| `Enter` | 下一张 |
| `s` | 跳过剩余卡片，直接进入正式复习 |
| `Esc` | 退出复习 |

自评会影响后续正式复习的重点：评为"模糊/不会"的概念会优先出现；全部"会了"则在更大范围随机出题。

### 阶段二：Formal Review（正式复习）

- **选择题**：`↑↓` 移动光标，或直接按 `A`–`D` 作答，`Enter` 提交。提交后立即显示对错与解析。
- **简答题**：在底部输入答案，`Enter` 提交。提交后显示得分、缺失要点与评语。
- **追问**：反馈停留时输入文字并 `Enter`，可针对本题继续追问。
- **下一题**：空 `Enter` 进入下一题（后台已提前生成，等待时显示"生成中…"）。
- **退出**：`Esc` 退出复习。

### 掌握度

每次作答都会记入学习历史。复习结束后显示小结：已掌握 / 需巩固的概念，以及下一步学习建议。答错的概念在后续复习中会优先出现。

## 复习地图（Review Map）

`Ctrl+K` → Review Map 查看当前课程的知识结构：

- 三级结构：**课程 → 章节 → 概念**
- 状态标记：✓ 已掌握 / △ 需巩固 / ○ 未复习
- `↑↓` 浏览，`Enter` 选中：概念可单独复习，章节可整节复习
- `Esc` 关闭

也可用 `Ctrl+K` → Outline 生成/查看大纲，`Outline → Export` 导出 Markdown 复习提纲。

---

## 笔记管理

`Ctrl+K` → Materials（或 `/notes`）打开笔记浏览器：

- 顶部输入关键词实时搜索笔记
- `↑↓` 移动光标，`Enter` 查看笔记内容（`PageUp/Down` 滚动预览）
- **多选**：选中多篇后可批量操作
- **移动**：把笔记移到另一门课程
- **删除**：删除笔记（仅删知识库记录，**不影响磁盘原文件**）
  - 删除较多笔记时有强确认（输入 `DELETE` 确认），防止误删

---

## 会话管理

- **恢复会话**：`Ctrl+K` → Recent Sessions，选择之前的对话继续提问
- **重命名**：Rename Session
- **删除**：在会话列表中选中后按 `d`，确认删除（当前打开的会话不可删除）
- **导出 / 加载**：Export Conversation 保存为文件；Load Conversation 从文件恢复——换设备也能带走进度

---

## 预算控制

`Ctrl+K` → Budget：

- 查看累计花费
- 设置上限（达到上限后自动停止 AI 调用，避免超支）
- 重置累计花费

预算覆盖所有 AI 调用（提问、导入、出题、批改、大纲），防止意外产生大量费用。

---

## 模型配置

### 切换模型

`Ctrl+K` → Model，列出所有服务商与模型：

- 直接选择某个模型 → 切换当前使用的模型
- 顶部可输入关键词过滤

### Model Roles（角色配置）

在 Model 面板顶部有三个角色：`fast` / `balanced` / `reasoning`：

- 选中角色 → 选择该角色使用的模型
- 配置后，对应任务自动使用该模型：`fast` 跑导入/大纲/复习地图/闪卡，`balanced` 跑普通问答/复习追问/正式出题/复习小结，`reasoning` 跑批改/错因分析/复杂推理
- 未配置的角色自动使用当前选择的模型

### 添加服务商

`Ctrl+K` → Model → 底部选择服务商并配置：选择 Provider → 选 Model → 填 API Key → 测试连接。

也支持 **Custom OpenAI-compatible**：自定义 Provider 名称、Base URL、Model 与 API Key，接入任意兼容 OpenAI 接口的服务。
