## 1. 文件系统是什么

**文件系统 (file system)** 管理磁盘块，向上提供一个**文件抽象**。

磁盘的物理结构——盘面分成磁道、磁道分成扇区——最终对外暴露的都是**块 (block)**。文件系统的工作就是把"一串连续的字节 + 一个可寻址的位置"（你在第 10 章看到的"文件 = 字节序列，带当前文件位置"）落实在底层的磁盘块上：你读写的第 $k$ 个字节，对应磁盘上某块的第 $k \bmod \text{blocksize}$ 个字节。

> 这一步把第 10 章的"文件"从**操作系统 I/O 的视角**（打开/读写/描述符）延伸到**它背后怎么存**：名字在哪儿、内容在哪些块上。

## 2. 格式化与超级块

**格式化 (formatting)** 是文件系统的起点：把原始的磁盘块整理成可管理的结构——

- 指定一个（或多个）块为 **"超级块" (super block)**；
- 把其余块登记为**空闲块**。

**超级块**是整个文件系统的"主块"，记录：类型信息、大小、**根目录**、空闲块。SFS 用扁平目录结构，所以根目录就放在超级块里。

## 3. 目录与名字

**目录 (directory) 是一个特殊文件**：它把**字符串映射到文件**，而那些被映射的"文件"本身又可以是目录（于是构成层次结构）。

查找一个文件，就是在一个目录里遍历条目、按名字匹配：

```c
for (fileEntry = 0; fileEntry < FILE_COUNT_LIMIT; fileEntry++) {
    if (superBlock->files[fileEntry].first_block != 0 &&        /* 已分配？ */
        strcmp(superBlock->files[fileEntry].name, fileName) == 0) { /* 名字匹配？ */
        return addOpenFileEntry(fileEntry);
    }
}
```

**关键辨析——名字只是键，不是内容**：文件的内容与它的"名字"是分开的；**扩展名不决定数据的类型**（`.png` 只是命名习惯，内核不据此解释字节）；名字只是一个**定位数据的键 (key)**。

## 4. 打开与读写文件

### 打开文件

打开 = ① 找到文件 → ② 建立三个表项：

1. 找到一个可用的**文件描述符**（第 10 章的表）；
2. 分配一个**打开文件表**条目（记录位置、权限等）；
3. 把文件信息**载入内存**。

> SFS 始终在内存中（见第 6 节），所以第 3 步是隐式的。

### 读文件：文件位置 → 磁盘块映射

读文件时，文件系统把**文件位置映射到磁盘块**。映射方式有很多种：

- **连续 (contiguous)**：文件的块连续存放，位置 → 块是简单偏移（快，但易碎片化）；
- **链式 / FAT (linked / FAT)**：每块存指向下一块的指针（或查文件分配表）；
- **索引式 (indexed)**：用一张索引块表列出文件的所有块（SFS 采用）。

### 写文件

和读类似，但文件**可能增长**——SFS 的做法是**预分配空间**（写时无需现找块），并带来有趣的同步问题（多进程同时写同一文件时）。

## 5. 删除文件

删除 = "像 `free()`，但…"——先问一句：**正在打开的文件能被删吗？**（POSIX 中可删：已打开的文件句柄仍有效，只是名字从目录移除。）

删除分两步：

1. **移除映射**（从目录里去掉这个名字）；
2. 把该文件占的块**放回空闲链表**。

## 6. SFS 具体实现

**SFS（Shark 文件系统）** 是这门课的 Lab 文件系统，几个具体点：

- 用 **`mmap` 把整个"磁盘"文件映射进内存**——把磁盘当成一个内存数组来操作（呼应第 9 章 mmap）；
- 把磁盘视为**512 字节块的数组**；
- **块 0 是超级块**，其他"指向 0"的引用一律视为 **NULL**（空指针）；
- **扁平目录结构**（没有子目录，所以根目录就在超级块里，查找只需线性扫一个数组）。

## 7. 总结

| 概念 | 要点 |
|---|---|
| **文件抽象** | 文件系统把磁盘块组织成"字节序列 + 文件位置" |
| **格式化** | 指定超级块、登记空闲块 |
| **超级块** | 类型/大小/根目录/空闲块；SFS 根目录在超级块内 |
| **目录** | 特殊文件，字符串 → 文件的映射，可嵌套 |
| **名字** | 只是键；内容与名字分离；扩展名不决定类型 |
| **打开** | 找文件 + 建三个表项（fd、打开文件表、内存信息） |
| **读写映射** | 连续 / 链式 FAT / 索引式；SFS 索引式 + 预分配 |
| **删除** | 移除映射 + 回收块；打开中的文件句柄仍有效 |
| **SFS** | mmap 整个磁盘、512B 块、块 0 = 超级块（其余 0 = NULL）、扁平目录 |
