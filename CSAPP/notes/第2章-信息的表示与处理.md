## 1. 基本概念

### 字节（Byte）

**1 Byte = 8 bits**

> 字节是内存编址的最小单位。所有数据在内存中最终都是以字节序列的形式存储的。1 字节大小恰好对应 C 语言中 `char` 类型的大小（`sizeof(char) = 1`）。

> **核心结论**：字节是内存编址的最小单位，1 字节 = 8 位，恰好对应 C 的 char 类型大小。

## 2. 位运算与移位

### 移位操作（Shift Operations）

#### 左移 `x << y`

- 将 $x$ 的二进制位向左移动 $y$ 位。
- **右侧补 $0$**，左侧移出的高位直接丢弃。

#### 右移 `x >> y`

将 $x$ 的二进制位向右移动 $y$ 位。分为两种类型：

- **逻辑右移（Logical Shift）**：左侧补 $0$。适用于无符号数。
- **算术右移（Arithmetic Shift）**：左侧补符号位（即最高位的值）。适用于有符号数，可保持负数的符号。

> **补充说明**：对有符号整数使用右移时，绝大多数编译器采用算术右移。但根据 C 标准，对有符号数的右移结果是**由实现定义的（implementation-defined）**，因此在可移植代码中应避免对有符号负数进行右移。

#### 未定义行为（Undefined Behavior）

以下情况属于 C 标准的未定义行为（UB）：

- 移位位数**小于 $0$**。
- 移位位数**大于等于字长**（word size，即类型的位宽）。

> 例如：对 `int` 类型（32 位）执行 `1 << 32` 或 `1 >> -1` 都是未定义行为——编译器可能给出任何结果，程序可能崩溃。

> **核心结论**：左移右侧补 0；右移分逻辑（补 0，无符号）与算术（补符号位，有符号）；移位位数为负或 ≥ 字长属于未定义行为。

## 3. 整数编码

### 无符号数（Unsigned）

无符号数的编码只表示非负整数。对于一个 $w$ 位的位向量 $\boldsymbol{x} = (x_{w-1}, \dots, x_0)$：

$$
\text{B2U}(\boldsymbol{x}) = \sum_{i=0}^{w-1} x_i \cdot 2^i
$$

取值范围：

$$
\text{UMin} = 0, \quad \text{UMax} = 2^w - 1
$$

### 补码（Two's Complement）

补码是目前几乎所有计算机表示有符号整数的方式。最高位为**符号位**，权重为 $-2^{w-1}$：

$$
\text{B2T}(\boldsymbol{x}) = -x_{w-1} \cdot 2^{w-1} + \sum_{i=0}^{w-2} x_i \cdot 2^i
$$

取值范围：

$$
\text{TMin} = -2^{w-1}, \quad \text{TMax} = 2^{w-1} - 1
$$

> **补码的非对称性**：`|TMin| = TMax + 1`，即 `-TMin = TMin`（因为 $-2^{w-1}$ 没有对应的正数表示）。

### 补码与无符号数的关系

对于同一个位向量 $\boldsymbol{x}$：

- **符号位为 $0$**：$\text{B2U}(\boldsymbol{x}) = \text{B2T}(\boldsymbol{x})$，两者相等。
- **符号位为 $1$**：$\text{B2U}(\boldsymbol{x}) = \text{B2T}(\boldsymbol{x}) + 2^w$，无符号数比补码大 $2^w$。

转换公式：

$$
\text{B2U}(\boldsymbol{x}) = \text{B2T}(\boldsymbol{x}) + x_{w-1} \cdot 2^w
$$

### 有符号数与无符号数的混合运算

在 C 语言中，当有符号数（Signed）和无符号数（Unsigned）出现在同一个表达式中时，有符号数会**隐式转换**为无符号数后进行运算。

#### 经典陷阱示例

```c
int i;
for (i = n - 1; i - sizeof(char) >= 0; i--) {
    // 这段代码永远不会退出！
}
```

> **原因**：`sizeof(char)` 返回类型为 `size_t`（无符号整数）。C 语言在有符号与无符号混合比较时，会将 `i` 隐式转换为 `unsigned`，因此 `i - sizeof(char) >= 0` 始终为真（因为无符号数永远不会小于 $0$）。

> **核心结论**：无符号 B2U 与补码 B2T 仅在最高位权重上不同（+2^w vs -2^w）；有符号与无符号混用时隐式转无符号，易踩永不退出陷阱。

## 4. 数值转换与运算

### 符号扩展（Sign Extension）

给定一个 $w$ 位的整数，将其转换为值相同的 $w+k$ 位整数。

**规则**：将最高位（符号位）复制 $k$ 次到高位。

- 若原最高位为 $0$：高位补 $0$，值不变。
- 若原最高位为 $1$：高位补 $1$。证明如下：

设原数 $x = -2^{w-1} + \sum_{i=0}^{w-2} x_i \cdot 2^i$，扩展后：

$$
x' = -2^{w+k-1} + \sum_{i=0}^{w+k-2} x_i' \cdot 2^i = \left(-2^{w+k-1} + \sum_{i=w-1}^{w+k-2} 2^i\right) + \sum_{i=0}^{w-2} x_i \cdot 2^i
$$

其中高 $k$ 位的求和构成等比数列：

$$
-2^{w+k-1} + \sum_{i=w-1}^{w+k-2} 2^i = -2^{w+k-1} + (2^{w-1} + \dots + 2^{w+k-2}) = -2^{w+k-1} + 2^{w+k-1} - 2^{w-1} = -2^{w-1}
$$

恰好等于原数中符号位的贡献，因此 $x' = x$。

> **反直观的事实**：对于 `short`（16 位）转 `int`（32 位），编译器会自动完成符号扩展——不是"保持位模式不变"，而是"保持数值不变"。

### 取负运算（Negation）

**规则**：对补码表示的整数取负，等价于"按位取反再加一"：

$$
-x = \sim x + 1
$$

**原理**：设 $x$ 的补码表示为 $\boldsymbol{x} = (x_{w-1}, \dots, x_0)$。按位取反后每一位满足 $x_i + \sim x_i = 1$。两数相加：

$$
\begin{aligned}
x + \sim x &= -\bigl(x_{w-1} + \sim x_{w-1}\bigr)2^{w-1} + \sum_{i=0}^{w-2}(x_i + \sim x_i)2^i \\
&= -1 \cdot 2^{w-1} + (2^{w-1} - 1) = -1
\end{aligned}
$$

因此 $\sim x = -1 - x$，两边同时加 $1$ 即得 $-x = \sim x + 1$。

> **边界情况**：`-TMin = TMin`。$TMin = 100\dots0_2$ 取反得 $TMax$，加一后溢出回到 $TMin$。这是因为补码值域不对称（正数比负数少一个），$2^{w-1}$ 超出了表示范围。

### 加法与乘法

无符号数和补码的加法与乘法：

- 先在二进制下进行运算（模 $2^w$）。
- 丢弃超出 $w$ 位的高位部分，只保留低 $w$ 位。
- 再将结果解释为对应的编码方式。

> **关键区别**：虽然无符号数和补码的加法/乘法在**位层面**完全一致的（都按模 $2^w$ 进行），但**溢出检测**的方式不同：
> - 无符号加法溢出：结果小于加数之一（回绕到 $0$）。
> - 补码加法溢出：正 + 正 = 负（正溢出）或 负 + 负 = 正（负溢出）。

### 用移位实现除法

右移 $k$ 位等价于二进制小数点左移 $k$ 位，即除以 $2^k$。丢弃的低位就是余数。

#### 无符号数除以 $2^k$

使用逻辑右移：

$$
u \gg k \;(\text{逻辑}) = \lfloor u / 2^k \rfloor
$$

> 结果总是向下舍入。无符号数非负，向下舍入 = 向 $0$ 舍入。

#### 补码正数除以 $2^k$

正数符号位为 $0$，算术右移高位补 $0$，与逻辑右移一致：

$$
x \gg k \;(\text{算术}) = \lfloor x/2^k \rfloor, \quad x \ge 0
$$

#### 补码负数除以 $2^k$

算术右移高位补 $1$，结果恰好等于**向下舍入**（向 $-\infty$ 方向）：

令 

$$
	u=\sum_{i=0}^{w-2}x_{i}2^i-2^{w-1} 
$$

算术右移之后的结果为

$$
	\sum_{i=1}^{w-2} x_{i}2^{i-1}+2^{w-2}-2^{w-1}=\sum_{i=1}^{w-2}x_{i}2^{i-1}-2^{w-2}=\frac{u-x_{0}}{2} 
$$

因此算术右移天然实现**向下取整（floor）**.

例如 `-7 >> 1`（4 位补码）：

| 步骤 | 值 | 二进制 |
|------|-----|--------|
| $x = -7$ | $-7$ | `1001` |
| $u = x + 16 = 9$ | $9$ | `1001` |
| $u \gg 1$ | $4$ | `0100` |
| $+ (16 - 8) = +8$ | $12$ | `1100` |
| 转补码 $- 16$ | **$-4$** | `1100` |

而 $\lfloor -7/2 \rfloor = \lfloor -3.5 \rfloor = -4$，一致。

> **偏置修正（向 0 舍入）**：C 的整数除法向 0 截断（truncation），而算术右移向 $-\infty$。若要模拟向 0 舍入，对负数预先加上 $(2^k - 1)$ 产生进位：
>
> ```
> (x < 0 ? x + (1 << k) - 1 : x) >> k
> ```
>
> 偏置值 $(2^k - 1)$ 是 $2^k$ 以下的最高值，负数不能被 $2^k$ 整除时，加上它后余数进位到商，从而把 floor 扳回 truncation。

> **核心结论**：符号扩展复制符号位保持数值不变；取负 = ~x+1；加法乘法按模 2^w 截断（位层面无符号/补码一致，溢出检测不同）；负数算术右移向下取整，模拟向 0 需偏置修正。

## 5. 浮点数（Floating Point）

### 基本格式

IEEE 754 标准：一个浮点数由三个字段编码：

$$
(-1)^s \times M \times 2^E
$$

- $s$（sign）：符号位，决定正负
- $M$（mantissa/significand）：尾数，$[1.0, 2.0)$
- $E$（exponent）：指数

**编码字段分配**：

| 精度 | $s$ | $\text{exp}$ | $\text{frac}$ | 总位数 |
|------|-----|-------------|--------------|--------|
| **单精度（float）** | 1 | 8 | 23 | 32 |
| **双精度（double）** | 1 | 11 | 52 | 64 |

**指数偏移**：$E = \text{exp} - \text{Bias}$，其中 $\text{Bias} = 2^{\,k-1} - 1$（$k$ 为指数位数）

- 单精度：$\text{Bias} = 2^{7} - 1 = 127$
- 双精度：$\text{Bias} = 2^{10} - 1 = 1023$

### 浮点数的分类

根据 $\text{exp}$ 的取值，浮点数分为三类：

#### 规格化数（Normalized）—— $\text{exp} \neq 000\dots0$ 且 $\text{exp} \neq 111\dots1$

$$
M = 1.\text{frac} \quad (\text{隐含前导 } 1)
$$

大部分浮点数属于此类。

#### 非规格化数（Denormalized）—— $\text{exp} = 000\dots0$

- $M = 0.\text{frac}$（**无**隐含前导 1）
- $E = 1 - \text{Bias}$（注意不是 $-\text{Bias}$）
- 用途：表示 $0$ 和**接近 $0$** 的值（逐渐下溢）
- $\text{exp} = 0$ 且 $\text{frac} = 0$ 时表示 $\pm 0$（符号位决定正负）

#### 特殊值（Special Values）—— $\text{exp} = 111\dots1$

| $\text{frac}$ | 含义 | 用途 |
|--------------|------|------|
| $\text{frac} = 0$ | $\pm\infty$ | 表示溢出 |
| $\text{frac} \neq 0$ | NaN（Not a Number） | 非法运算结果（如 $0/0$, $\sqrt{-1}$） |

### 舍入（Rounding）

浮点数精度有限，运算结果需要舍入到目标位数。

四种舍入模式：

| 模式 | 规则 |
|------|------|
| **向 $0$ 舍入**（Round toward Zero） | 直接截断多余位 |
| **向上舍入**（Round Up / $+\infty$） | 向 $+\infty$ 方向取整 |
| **向下舍入**（Round Down / $-\infty$） | 向 $-\infty$ 方向取整 |
| **向最近偶数舍入**（Round to Nearest Even, **默认**） | 舍入到最接近的值，正好在中点时向偶数舍入 |

> **向最近偶数舍入**是 IEEE 754 默认模式。它在统计上无偏——50% 概率向上、50% 概率向下。
>
> **十进制例子**（百分位舍入）：$1.2349999 \to 1.23$，$1.2350000 \to 1.24$（$1.24$ 更接近 $1.24$，且 $4$ 为偶数）。

### 浮点运算

#### 乘法

$$
(-1)^{s_1}M_12^{E_1} \times (-1)^{s_2}M_22^{E_2}
$$

步骤：

1. **符号**：$s = s_1 \oplus s_2$（异或）
2. **指数**：$E = E_1 + E_2$
3. **尾数**：$M = M_1 \times M_2$
4. **规格化**：若 $M \ge 2$，则 $M$ 右移一位，$E$ 加一
5. **舍入**：将 $M$ 舍入到 $\text{frac}$ 位数
6. **溢出检查**：若 $E$ 超出可表示范围，返回 $\pm\infty$

#### 加法

$$
(-1)^{s_1}M_12^{E_1} + (-1)^{s_2}M_22^{E_2}
$$

步骤：

1. **对阶**：将指数较小的数的尾数右移，使两数指数相等
2. **尾数相加**：两尾数相加（考虑符号位后的实际数值）
3. **规格化**：必要时左移/右移尾数并调整指数
4. **舍入**：舍入到目标精度

#### 浮点数运算的陷阱

有限的尾数位数导致精度损失，**结合律不成立**：

```c
// 加法结合律失效（单精度）
(3.14 + 1e10) - 1e10 == 0   // 而非 3.14！
```

> $3.14$ 与 $1\text{e}10$ 相加时，$3.14$ 在对阶右移中完全移出了 23 位尾数的范围，丢失殆尽。

```c
// 乘法结合律失效
(1e20 * 1e20) * 1e-20 == inf   // 中间结果溢出
```

> $1\text{e}20 \times 1\text{e}20 = 1\text{e}40$，单精度指数溢出到 $\infty$。


> **核心结论**：IEEE 754 = (-1)^s × M × 2^E，分规格化/非规格化/特殊三类；舍入默认向最近偶数（统计无偏）；精度有限导致结合律不成立。

## 6. 字长与字节序

### 字长（Word Size）

字长是指 CPU 一次能并行处理的二进制位数，也是指针类型的大小。常见的字长：

- 32 位系统：字长 = 4 字节，指针占 4 字节。
- 64 位系统：字长 = 8 字节，指针占 8 字节。

> 字长决定了虚拟地址空间的大小：32 位系统最多寻址 $2^{32} = 4\text{GB}$，64 位系统最多寻址 $2^{64}$ 字节（理论上限极大，实际受硬件限制）。

### 字节序（Endianness）

字节序描述的是多字节数据在内存中的字节排列顺序。对于整数 `0x01234567`（占 4 字节），两种字节序的存储方式如下：

| 内存地址 | 小端序（Little-Endian） | 大端序（Big-Endian） |
|----------|------------------------|---------------------|
| `&val`   | `0x67`（最低有效字节）| `0x01`（最高有效字节）|
| `&val+1` | `0x45`               | `0x23`              |
| `&val+2` | `0x23`               | `0x45`              |
| `&val+3` | `0x01`（最高有效字节）| `0x67`（最低有效字节）|

- **小端序（Little-Endian）**：最低有效字节（LSB）存储在最低地址。x86/x86-64 架构使用小端序。
- **大端序（Big-Endian）**：最高有效字节（MSB）存储在最低地址。网络字节序使用大端序（即传输 TCP/IP 数据包时使用大端序）。

> **实用提示**：当用 `gdb` 调试或 `objdump` 查看二进制数据时，了解字节序对于正确解读内存中的原始字节至关重要。

#### 查看字节序的代码

```c
#include <stdio.h>
#include <string.h>

// unsigned char * 类型：严格占用 1 字节，无符号位。
// 用此类型作为指针，加 1 时精确移动 1 个字节。
typedef unsigned char *pointer;

/**
 * 逐字节打印内存内容
 * @param start: 目标对象的起始地址
 * @param len:   要查看的字节数
 */
void show_bytes(pointer start, size_t len) {
    for (size_t i = 0; i < len; i++) {
        // %p: 地址；%.2x: 2 位十六进制，不足补 0
        printf("%p\t0x%.2x\n", start + i, start[i]);
    }
    printf("\n");
}

void show_int(int val) {
    // 强制转为 pointer 类型，以逐字节查看
    show_bytes((pointer) &val, sizeof(int));
}

int main() {
    int test_val = 0x01234567; // 便于观察字节序
    printf("测试值: 0x01234567\n");
    printf("地址\t\t数据\n");
    printf("----------------------------\n");
    show_int(test_val);
    return 0;
}
```

在 x86-64 机器上运行上述代码时，输出中 `0x67`（最低有效字节）将出现在最低地址——因为 x86-64 是小端序架构。

> **核心结论**：字长决定指针大小与寻址范围（32 位 4GB、64 位极大）；x86-64 用小端序（LSB 在低地址），网络字节序用大端。

## 7. 习题与思考

### 思考题

判断以下表达式的值（假设 `x` 是 `int` 类型，32 位）：

```c
(x | -x) >> 31 == -1
```

**分析**：对一个数的补码表示而言：

- 当 `x > 0` 时，`x` 与 `-x` 互为相反数，`x | -x` 的结果**符号位一定为 1**（因为 `-x` 的最高位为符号位，负数时最高位为 1）。算术右移 31 位后得到 `-1`（即全 1 的位模式）。表达式为真。
- 当 `x = 0` 时，`0 | 0 = 0`，右移 31 位后仍为 `0`，不等于 `-1`。表达式为假。
- 当 `x < 0` 时，`-x` 为正，`x | -x` 的结果符号位仍为 1（因为负数 `x` 的最高位为 1）。因此右移结果也为 `-1`。表达式为真。

**结论**：当 `x = 0` 时结果为假（`0`）；否则为真（`1`）。因此该表达式**不恒等于** `-1`。

> 此题的底层原理：`x | -x` 的作用是保留 $x$ 中最低位的 1 并将其左侧全部置为 1。当 $x \neq 0$ 时，结果必然是负数；当 $x = 0$ 时，结果仍为 $0$。

### 浮点思考题

1. **判据**：对于任意浮点数 $d$，以下是否总成立？
   - $d < 0 \implies d \times 2 < 0$
   - $d \times d \ge 0$

   > **答案**：均成立。浮点数的符号位 $s$ 独立存储，乘 2 只改变指数；同号相乘或 $0 \times 0$ 均为非负。

2. **乘法溢出**：两个很大的浮点数相乘，指数相加时发生上溢，结果会怎样？

   > **答案**：规格化后若指数 $E$ 超出最大可表示范围，结果溢出到 $\pm\infty$（$\text{exp} = 111\dots1$，$\text{frac} = 0$）。若指数极大（如 $1\text{e}40$），中间结果直接 $\to \infty$。

> **核心结论**：(x|-x)>>31==-1 在 x≠0 时恒真、x=0 时假；浮点乘 2 只改指数，指数上溢时结果为 ±∞。

## 总结

| 概念 | 要点 |
|------|------|
| 移位 | 左移补 0；逻辑右移补 0，算术右移补符号位 |
| 补码 | 最高位权重为负，`-TMin = TMin` |
| 符号扩展 | 复制最高位，保持数值不变 |
| 取负 | 按位取反加一 |
| 加法/乘法 | 二进制运算后截断，位层面 unsigned 和 two's complement 一致 |
| 除法（移位） | 负数算术右移向下舍入，需偏置修正 |
| 浮点数 | $(-1)^s \times M \times 2^E$；分三类：规格化/非规格化/特殊 |
| 舍入 | 默认向最近偶数舍入（统计无偏）|
