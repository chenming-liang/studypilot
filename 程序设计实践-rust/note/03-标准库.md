## 字符串 (Strings)

> 字符串处理是 Rust 里最容易踩坑的地方，根源在于它用 UTF-8 编码，并且区分"拥有型"（`String`）和"借用型"（`&str`）两种类型。

### 字符编码 (Character Encoding)

**动机**：字符串底层是字节序列，不同编码决定"一个字符占几个字节"。

- 早期 **ASCII**：以英文字符为主，7 位二进制。
- 中文 **GB 2312-1980**：6,763 个汉字，两个字节；**GB 18030-2005**：70,244 个汉字，两个或四个字节。
- **Unicode**：试图纳入全世界文字（Unicode 15.1 含 161 种文字的 149,813 个字符），常用 **UTF-8** 表示，变长一到四个字节。

**Rust 的选择**：字符串是 **UTF-8 编码的 Unicode 字符序列**，不是 `'\0'` 结尾的 C 风格字符串（可以包含空字符）。

### 三种字符串类型：str / &str / String

**定义：** Rust 有两种可用的字符串类型，以及它们背后的无大小类型：

- **`String`**：分配在**堆**上、可**动态增长**；本质上就是给 `Vec<u8>` 包了一层。
- **`&str`**：`String` 的**切片**（字符串切片），是切片的一种；形如 `"foo"` 的字符串字面值都是 `&str`。
- **`str`**：`&str` 去掉引用后的**无大小类型 (unsized type)**——编译时大小未知，**不能直接绑定**，只能通过引用的形式（`&str`）使用。

```rust
let s0: String = String::new();
let s1: String = "foo".to_string();
let s2: String = String::from("bar");
let s3: &str = "galaxy";   // 字面值
let s4: &str = &s0;        // 取引用得到 &str
```

### 为什么不能按字节下标索引

**注意**：不能写 `some_str[i]`——**每个 Unicode 字符可能占多个字节**，`[i]` 按字节下标会切到字符中间。正确做法是**在 `chars()` 上迭代**：

```rust
for c in "1234".chars() {
    // c 是 char（一个完整的 Unicode 字符）
}
```

`String` 同样不能用下标，可用 `s.chars().nth(i)` 访问第 `i` 个字符。

### 字符串连接（`+` 与移动）

**定义：** `+` 可以把 `String` 与 `&str` 连接，但**左操作数 `String` 会被移动**——`+` 调用的实现是 `fn add(mut self, other: &str) -> String`，它吃掉了左边的 `self`：

```rust
let a = String::from("hello");
let b = String::from(" world");
let c = a + &b;   // a 被移动，之后不能再使用
// let d = a;     // 错误：a 已移动
```

想保留第一个 `String`，先做克隆：

```rust
let c = a.clone() + &b;   // a 仍有效
```

连接两个 `&str` 需要先把第一个转成 `String`：

```rust
let c = "hello".to_string() + " world";
```

更简洁的做法是用宏：`format!("{a}{b}")`。

### String 与 &str 并存的设计原因

- `&str` 提供 `String` 的一个**视图**，正如切片之于数组/`Vec`。
- 拷贝 `String` 代价大，而且借用时不一定需要整个字符串。
- `&str` 提供了一种**低开销传递部分字符串**内容的方法，节约内存。
- **实践惯例**：处理字符串通常用 `String`，同时用 `&str` 借用其中的内容。

### &str 与 String 的转换与方法（常见易错点）

**创建 `String` 的四种写法**——`to_string()` / `String::from` / `to_owned()` / `into()`，都产生**新的堆上副本**，原 `&str` 不受影响：

```rust
let a: String = "foo".to_string();   // ToString trait
let b: String = String::from("foo"); // From trait
let c: String = "foo".to_owned();    // ToOwned trait（更通用：&str→String、&[i32]→Vec<i32>）
let d: String = "foo".into();        // Into trait（From 的反向）
```

- **注意**：`into()` 靠目标类型推断，必须写类型标注（`let s: String = "foo".into();`），不能裸写 `let s = "foo".into();`。

**常用处理方法**（`trim`/`replace`/`to_lowercase` 在 `String` 上也可调用——`String` 可 deref 成 `&str`）：

```rust
let s = "  hello  \n";
s.trim();                        // "hello"：去首尾空白（含 \t、\n），返回 &str（零分配）
let s2 = "my cars";
s2.replace("cars", "balloons");  // "my balloons"：替换，返回新 String
let s3 = "HeLLo".to_lowercase(); // "hello"：转小写，返回新 String
```

- **注意**：返回值类型不同——`trim()` 返回 **`&str`**（借用、不分配内存），`replace()`/`to_lowercase()` 返回**新 `String`**（需要分配）；且后两者**不修改原字符串**，必须接住返回值：
  ```rust
  let mut s = String::from("HeLLo");
  s.to_lowercase();        // 结果被丢弃，s 仍是 "HeLLo"
  s = s.to_lowercase();    // 要这样接住
  ```
- 常用组合：`input.trim().to_string()`——trim 后要 `String` 需再转换一次；猜数游戏的 `guess.trim().parse()` 正是靠 trim 容忍输入带换行。
- 拼接多个值用 `format!`（见第 1 讲），不移动参数、不要求左 `String` 右 `&str`。

## Option 枚举 (Option<T>)

> 遇到"可能没有值"的情况，Rust 不返回 `null`/`-1`/`NaN` 这类魔法值，而是用 `Option<T>` 在类型里明确表达"有值或空"。

### 定义

**定义：** `Option<T>` 是**泛型枚举**（和类型），表示"要么有值、要么没有"：

```rust
enum Option<T> {
    None,
    Some(T),
}
use Option::{None, Some};
```

- 为任意已有类型 `T` 提供"表示没有或空值"的概念，`T` 没有任何限制。
- Rust 中需要返回空值时**推荐用 `Option<T>`**，而不是返回 `NaN`、`-1`、`null` 等特殊值。

### 典型用途

- 初始值。
- 函数定义域不是全集。
- 表示简单的错误情况。
- 结构体的可选域或可拿走的域。
- 可选的函数参数。
- 替代空指针。

### 取出值的方法

> `Option<T>` 像一个"箱子"：要么 `Some(值)`、要么空 `None`，这些方法都是在"有值"时做不同的事。下面统一用 `x: Option<i32>` 演示；`|v| ...` 是**闭包**（lambda），语法见 [[#闭包语法 (Closures)|闭包语法]]。

**`unwrap()` / `expect(msg)`**：直接把值"掏出来"；箱子是空的就**恐慌**。看实现就一目了然——空箱子直接 `panic!`：

```rust
// 标准库实现（示意）
fn unwrap(self) -> T {
    match self {
        None => panic!("called `Option::unwrap()` on a `None` value"),
        Some(value) => value,
    }
}

let v1 = Some(5).unwrap();                    // v1: i32 = 5
let v2 = Some(5).expect("不可能是 None");     // 同 unwrap，但可自定义恐慌信息
```

**`map(f)`**：**变换**——有值就把值换成另一种类型，空就保持 `None`。看实现的关键一行 `Some(x) => Some(f(x))`：**闭包返回普通值、`map` 自动包一层 `Some`**：

```rust
fn map<U, F>(self, f: F) -> Option<U> where F: FnOnce(T) -> U {
    match self {
        None => None,
        Some(x) => Some(f(x)),   // ← 这里自动包 Some
    }
}

let s = Some(5).map(|v| v.to_string());   // Some("5")，类型 Option<String>
```

`map` 把 `Option<T>` 变成 `Option<U>`：`T` 是原元素类型（`i32`），`U` 是变换后的新元素类型（`String`），由闭包返回什么推断出来。

**`and_then(f)`**：**链式继续**——有值就"再跑一个也可能失败的步骤"。对照 `map` 的实现，`and_then` 是 `Some(x) => f(x)`：**闭包自己返回 `Option`，`and_then` 不再包**：

```rust
fn and_then<U, F>(self, f: F) -> Option<U> where F: FnOnce(T) -> Option<U> {
    match self {
        Some(x) => f(x),   // ← 直接用闭包的结果（已是 Option），不包
        None => None,
    }
}

fn checked_divide(a: i32, b: i32) -> Option<i32> {
    if b == 0 { None } else { Some(a / b) }
}
let r = Some(5).and_then(|v| checked_divide(100, v));   // Some(20)
```

**map 与 and_then 的区别**：

- **`map`** 来自函数式"**映射**"传统（Haskell `fmap`、Python `map`）：把函数应用到箱子内的值上，内容从 `T` 变 `U`——强调"变换"，闭包返回**普通值**，由 `map` 自动包 `Some`。
- **`and_then`** = **and（逻辑与）+ then（然后）**：`and` 表示两步**都成功**才成功（`Some` 且下一步 `Some` → `Some`；任一步 `None` → `None`，像逻辑与）；`then` 表示**顺序**——先用第一步的值，然后拿它算下一步。所以闭包返回 **`Option<U>`**（下一步也可能失败），`and_then` 直接用、不包。

对照实现里 `Some(x) => ...` 那一行：

| | `map` | `and_then` |
|---|---|---|
| 实现 | `Some(x) => Some(f(x))`（包一层） | `Some(x) => f(x)`（直接用） |
| 闭包返回 | `U`（普通值） | `Option<U>`（可能失败） |
| 名字含义 | 映射：变换内容 | and：都成功才成功 + then：接着算下一步 |

**判断口诀**：闭包结尾要写 `Some(...)` 就用 `and_then`；闭包返回普通值、靠外层包的用 `map`。

**`unwrap_or(default)` / `unwrap_or_else(|| ...)`**：空箱子用默认值兜底。看实现同样清楚——`unwrap_or` 直接给值，`unwrap_or_else` 用闭包**惰性计算**默认值：

```rust
fn unwrap_or(self, default: T) -> T {
    match self {
        None => default,
        Some(value) => value,
    }
}
fn unwrap_or_else<F>(self, f: F) -> T where F: FnOnce() -> T {
    match self {
        None => f(),
        Some(value) => value,
    }
}

let v = x.unwrap_or(42);              // 空则取 42
let v = x.unwrap_or_else(|| 1 + 41);  // 空则惰性计算默认值
```

**命名规律（`_else` 后缀）**：`unwrap_or` vs `unwrap_or_else`、`map_or` vs `map_or_else`、`or` vs `or_else`——不带 `_else` 给**现成的值**，带 `_else` 给**闭包惰性计算**兜底值（默认值昂贵时才值得算）。

**其他常用方法**：`is_some`/`is_none`（判断）、`map_or`/`map_or_else`、`ok_or`/`ok_or_else`（转 `Result`）、`and`/`or`/`xor`（组合两个 `Option`）。

**注意**：方法很多，可以凭"参数与返回值的类型"在 Rust 文档中搜索——例如搜 `Option<T> -> Option<U>` 能同时找到 `and`/`zip`/`map`/`and_then`/`zip_with` 等方法。

### 例子

```rust
fn divide(numerator: f64, denominator: f64) -> Option<f64> {
    if denominator == 0.0 {
        None
    } else {
        Some(numerator / denominator)
    }
}

match divide(2.0, 3.0) {
    Some(x) => println!("Result: {x}"),
    None => println!("Cannot divide by 0"),
}
```

## 错误处理 (Error Handling)

> 错误有两种：可以恢复的和不能恢复的。Rust 用 `Result` 处理可恢复错误、用 `panic!` 处理不可恢复错误，并用 `?` 操作符免去手工传递错误。

### 演进：C 错误码 → C++ 异常 → Rust Result

- **C**：**错误码**，用返回值表示错误。需要检查每个函数调用的返回值，错误处理代码分散在各处、难以维护。
- **C++**：**异常 `try/catch`**，可跨函数边界传播；但要手动抛出和捕获，抛出时需要**栈回退 (stack unwinding)**，带来额外性能开销。
- **Rust**：**`Result` 返回值类型**，在类型系统里显式表达"这个函数可能失败"——不靠魔法值、不靠运行时跳转，效率与显式性兼得。

### panic! 还是 Result？

**定义：** Rust 把错误分成两类：

- **不可恢复的错误** → `panic!`（恐慌）：数组越界、栈越界、算术运算溢出……
- **可恢复的错误** → `Result`：文件操作、网络操作、字符串解析……

### Result<T, E>

**定义：** `Result<T, E>` 是泛型枚举：正常结果带 `T`，错误带 `E`：

```rust
enum Result<T, E> {
    Ok(T),
    Err(E),
}
use Result::{Ok, Err};
```

- 与 `Option` 类似，也定义了 `unwrap`/`expect` 等方法。
- 可通过 `ok()`/`err()` 转换成 `Option`（把 `Ok`/`Err` 当 `Some`，另一种变 `None`）。
- 也可以做类似 `Option` 的操作（`and`、`or` 等）。

**处理原则**：返回 `Result` 的函数**一定要显式处理**——用 `unwrap`/`expect` 或 `match` 合理处理 `Ok`/`Err` 状态；**不处理编译器会发出警告**，不正确处理可能带来潜在问题。

```rust
fn divide(n: f64, d: f64) -> Result<f64, String> {
    if d == 0.0 {
        return Err(String::from("Cannot divide by zero"));
    }
    Ok(n / d)
}
```

### 自定义 Result 别名

**定义：** 库中常见做法是自定义错误类型，并固定 `E` 定义 `Result` 的别名：

```rust
use std::io::Error;
type Result<T> = std::result::Result<T, Error>;
// 之后 fn read_config() -> Result<()> 等价于 std::result::Result<(), Error>
```

**注意**：使用时要留意名字空间——`std::io` 也导出了 `io::Result<T>`（即 `Result<T, io::Error>`）。

### ? 操作符

**定义：** `?` 在返回 `Result` 或 `Option` 的函数中**提前传播错误**：

- 对 `Result`：是 `Err` 就**提前返回**该错误；否则从 `Ok` 中取出值作为 `?` 的结果。
- 对 `Option`：是 `None` 就**提前返回** `None`；否则从 `Some` 中取出值。

```rust
fn read_username_from_file() -> Result<String, io::Error> {
    let mut username = String::new();
    File::open("hello.txt")?.read_to_string(&mut username)?;
    Ok(username)
}

fn last_char_of_first_line(text: &str) -> Option<char> {
    text.lines().next()?.chars().last()
}
```

**语义**：`?` 是"成功就继续、失败才提前返回"——遇到错误/空值，函数在那一行**直接返回**（`Result` 函数返 `Err`、`Option` 函数返 `None`），后面的代码不再执行；遇到成功则解包出值、继续往下走。

**例 1 拆解**：

- `File::open("hello.txt")` 返回 `Result<File, io::Error>`（打开文件可能失败）。`?`：`Err` 立刻返回该错误；`Ok` 解包出 `File`，继续调 `.read_to_string(&mut username)`。
- `.read_to_string(&mut username)` 也返回 `Result<usize, io::Error>`（读取可能失败）。再一个 `?`：`Err` 立刻返回，`Ok` 解包（那个字节数我们不关心）。
- 全程无错才走到最后的 `Ok(username)`。

没有 `?` 时的等价展开（一眼看清它省了什么）：

```rust
fn read_username_from_file() -> Result<String, io::Error> {
    let mut username = String::new();
    let file = match File::open("hello.txt") {
        Ok(f) => f,
        Err(e) => return Err(e),      // ← ? 干的就是这行
    };
    match file.read_to_string(&mut username) {
        Ok(_) => {}
        Err(e) => return Err(e),      // ← ? 干的就是这行
    };
    Ok(username)
}
```

**例 2 拆解**：

- `text.lines()`：按行切分得到行迭代器；`.next()` 取第一行，返回 `Option<&str>`（空文本 → `None`）。
- `?`：`None` 立刻返回 `None`；`Some` 解包出第一行，继续 `.chars().last()`。
- `.chars().last()` 返回 `Option<char>`，正好是函数返回类型——作为尾表达式直接返回，**不再放 `?`**（放了会解包成 `char`，得 `Some(...)` 包回来才匹配返回类型）。

**判断方法**：`?` 放在"可能失败/可能为空"的表达式后面——解包成功值，失败则提前返回（`Result` 函数返 `Err`、`Option` 函数返 `None`）。

### 何时恐慌（处理原则）

**判断标准**：错误发生后程序是否进入一个**坏的状态 (bad state)**？

- **坏状态**是指不经常出现的情况（不像"用户输入不合法"这种经常出现的情况）、之后的代码依赖"程序不处于坏状态"、且无法用目前使用的类型表示这种信息。
- **`unwrap`/`expect` 的合法场合**：作为原型代码中的错误处理占位符；或调用方有更多信息、能保证调用一定不出错。

## 容器 (Containers)

> 标准库容器围绕"访问复杂度"和"是否有序"来选型；它们的共同点是都遵守所有权规则（插入即移动/拷贝）。

### 序列类容器

- **`Vec<T>`**：连续空间、可增长的序列，**末尾**高效增删，最常用的容器。
- **`VecDeque<T>`**：双端向量，**两端**都高效增删，用**环状缓冲区**实现。
- **`LinkedList<T>`**：双向链表，**不能随机索引**。

### 映射类容器

**定义：** 映射/字典类型，按需选型：

- **`HashMap<K, V>`**：哈希表实现，**无序**，$O(1)$ 访存；要求 `K: Hash + Eq`。
- **`BTreeMap<K, V>`**：B 树实现，**有序**，$O(\log n)$ 访存；要求 `K: Ord`。

```rust
use std::collections::HashMap;

let mut scores = HashMap::new();
scores.insert(String::from("Blue"), 10);
scores.insert(String::from("Yellow"), 50);

let team_name = String::from("Blue");
let score = scores.get(&team_name);          // Option<&i32>

for (key, value) in &scores {                // 迭代
    println!("{}: {}", key, value);
}
```

### 哈希表与所有权

**注意**：插入哈希表时，**`Copy` 类型拷贝进去，非 `Copy` 类型移动进去**（哈希表拥有所有权）：

```rust
let field_name = String::from("Favorite color");
let field_value = String::from("Blue");
let mut map = HashMap::new();
map.insert(field_name, field_value);
// 之后 field_name 和 field_value 都已失效（被移动进 map）
```

### 更新哈希表

```rust
scores.insert(String::from("Blue"), 10);           // 改写

scores.entry(String::from("Blue")).or_insert(50);  // 不存在时才添加

// 基于旧值更新（词频统计经典写法）
let text = "hello world wonderful world";
let mut map = HashMap::new();
for word in text.split_whitespace() {
    let count = map.entry(word).or_insert(0);
    *count += 1;
}
```

### 集合与优先队列

- **`HashSet<T>` / `BTreeSet<T>`**：元素唯一的集合，就是对 `HashMap<T, ()>` / `BTreeMap<T, ()>` 包一层；需求与表现跟相应的 Map 相同。
- **`BinaryHeap<T>`**：用二叉**最大堆**实现的优先级队列，弹出元素时返回当前最大值。

### get_disjoint_mut（Rust 1.86）

**定义：** 借用规则（多读单写）本来不允许同时取得多个可变引用——`&mut v[0]` 和 `&mut v[1]` 共存会报 `E0499`（都派生自同一个 `&mut v`）。Rust 1.86 起，`Vec`/`HashMap` 提供 `get_disjoint_mut`，传一组**互不相同**的位置，安全地同时拿到多个可变引用：

```rust
let mut v = vec![1, 2, 3, 4, 5, 6];

// 传索引数组 [0, 5] → 返回两个元素的可变引用 [&mut i32; 2]
let [a, b] = v.get_disjoint_mut([0, 5]).unwrap();
*a += 10;
*b += 10;

// 传范围数组 [0..2, 3..5] → 返回两个互不重叠的可变切片 [&mut [i32]; 2]
let [s1, s2] = v.get_disjoint_mut([0..2, 3..5]).unwrap();
s1[0] += 100;

// HashMap：传键数组 ["Blue", "Yellow"] → 返回 [Option<&mut V>; 2]，键不存在时为 None
let [blue, yellow] = scores.get_disjoint_mut(["Blue", "Yellow"]);
if let Some(b) = blue { *b += 1; }
if let Some(y) = yellow { *y += 1; }
```

**之前的安全替代**：`split_at_mut(mid)`（切成两个互不重叠的切片）、`get_many_mut([i, j])`（Rust 1.54，只支持索引）、`iter_mut()`（顺序地一次给一个 `&mut`）——`get_disjoint_mut` 是更通用的升级版（支持范围与 Map 键）。

## 迭代器 (Iterators)

> 迭代器把"怎么遍历"抽象成一个统一的 `Iterator` 接口，配一批**惰性适配器**和**急切汇聚**方法，让数据处理变成链式表达式。

### 闭包语法 (Closures)

**定义：** **闭包 (closure)** 就是 Rust 的**匿名函数 (anonymous function)**（lambda）：用 `|参数| 函数体` 表示，能捕获外层变量，可作高阶函数（`map`/`filter`/`fold`）的参数，参数类型由上下文推断：

```rust
let f = |x| x + 1;         // 一个参数
let g = |a, b| a + b;       // 多个参数
let h = || 42;              // 零参数
let offset = 10;
let k = |x| x + offset;     // 捕获外层变量 offset
```

**注意（所有权语义）**：闭包捕获外层变量的方式由"怎么用"决定——默认按需**借用**（引用/可变引用）；加 `move` 则**按值移入所有权**（闭包要跨作用域存活时用）。对应三个 trait：`Fn`（只读捕获、可多次调用）、`FnMut`（可变捕获）、`FnOnce`（消费捕获、只能调一次）——`map` 要求 `FnOnce`，`fold` 要求 `FnMut`。闭包编译期**零开销**（展开为匿名结构体 + 调用）。

### Iterator trait

**定义：** 迭代器特型包含一个**关联类型 `Item`** 和产生下一个元素的方法 **`next`**：

```rust
pub trait Iterator {
    type Item;
    fn next(&mut self) -> Option<Self::Item>;
    // 其余方法用 next 的默认实现
}
```

`next` 返回 `Option<Item>`：`Some` 表示还有元素，`None` 表示迭代结束。

### 三种迭代类型（与所有权）

- `into_iter()`：产生 **`T`**（拿走所有权）。
- `iter()`：产生 **`&T`**（不可变借用）。
- `iter_mut()`：产生 **`&mut T`**（可变借用）。

集合可以提供部分或全部这三种接口。

### for 循环的展开

**定义：** `for ... in ...` 是**语法糖**，展开为 `into_iter()` + `while let` 循环：

```rust
for i in 0..10 { println!("{}", i); }
// 展开为：
let mut iter = (0..10).into_iter();
while let Some(i) = iter.next() {
    println!("{}", i);
}
```

### 汇聚操作（急切求值）

- **`collect()`**：把（惰性的）迭代器变成一个实际的集合。结果类型有时需要提示才能推断：

```rust
let vs = vec![1, 2, 3, 4];
let set: HashSet<_> = vs.iter().collect();          // 类型提示
let set = vs.iter().collect::<HashSet<_>>();        // 或 turbofish ::<>
```

**机制（类型决定行为）**：签名是 `fn collect<B>(self) -> B where B: FromIterator<Self::Item>`——`collect` 本身不决定怎么收集，行为由**目标类型 `B` 的 `FromIterator` 实现**说了算：同一个迭代器收进不同集合，结果不同（保序/去重/短路等）。`B` 由类型推断确定（`let` 注解、`::<>` turbofish、函数返回类型）；**编译期已确定，无运行期分发，零开销**：

```rust
let v: Vec<i32> = vec![1, 1, 2, 3].into_iter().collect();        // 保序、保留重复
let s: HashSet<i32> = vec![1, 1, 2, 3].into_iter().collect();    // 去重、乱序
let m: HashMap<_, _> = vec![("a", 1), ("b", 2)].into_iter().collect();  // (K, V) 对 → 键值表
let st: String = ['h', 'i'].into_iter().collect();               // char → 拼接字符串
let ok: Option<Vec<i32>> = [Some(1), Some(2)].into_iter().collect();    // 全 Some → Some
let bad: Option<Vec<i32>> = [Some(1), None].into_iter().collect();      // 遇 None → 整体 None（短路）
let r: Result<Vec<i32>, &str> = [Ok(1), Err("boom")].into_iter().collect(); // 遇 Err → 整体 Err
let arr: [i32; 3] = (1..=3).collect();                           // 定长数组：长度必须恰好匹配
```

**注意**：`Option`/`Result` 作为目标类型时是**整体短路**——中间有一个 `None`/`Err`，整个收集变成 `None`/`Err`，不会"跳过坏元素保留好的"（想要后者用 `filter_map`/`flatten`）。

<!-- 讲义 3.5.5 仅给 HashSet 例子；"行为由目标类型 FromIterator 决定"的机制说明及 Option/Result/String/数组等例子补充自标准知识 -->

- **`fold(init, f)`**：把迭代器折叠成一个单一的值（其他语言称 reduce / inject）；参数是初始值 `acc` 和折叠函数 `(acc, item) -> acc`：

```rust
let sum = vs.iter().fold(0, |acc, &x| acc + x);   // 15
```

- **`find(p)` / `position(p)`**：找第一个满足谓词的元素——`find` 返回元素本身，`position` 返回索引；没找到都返回 `None`。
- **`any(f)` / `all(f)`**：是否存在一个元素符合 / 是否所有元素都符合给定函数，返回 `bool`（对应逻辑或/逻辑与）。

### 迭代器适配器（惰性）

**定义：** **适配器 (adapter)** 吃一个迭代器、返回另一个迭代器，并且**惰性**——除非显式使用（`collect`/`for` 循环）否则不求值：

- **`map(f)`**：在每个元素上作用函数，完成 `Collection<A> + (A -> B) => Collection<B>`。
- **`filter(p)`**：去掉不满足谓词的元素。
- **`take(n)` / `take_while(p)`**：取前 `n` 个 / 取到谓词返回 `false` 为止；可在无限范围上得到有限序列（`(0..).take(5)`）。
- **`skip(n)`**：跳过前 `n` 个元素。
- **`enumerate()`**：迭代时同时给序号，产出 `(index, value)`，`index` 是 `usize`。
- **`zip(other)`**：把两个迭代器逐项合并成 `(a, b)` 对；任一个输入结束，整个 `zip` 就结束。
- **`chain(other)`**：把两个迭代器**首尾相接**成一个：先产出第一个的全部元素、再产出第二个的全部元素（长度相加，与 `zip` 的"取短缝合"相反）；参数是 `IntoIterator`（迭代器 / `Vec` / 切片 / 范围都可直接传），两者 `Item` 类型必须一致；惰性，且**消费两个迭代器对象**——借用（`a.iter()`）则数据仍归原变量，move（`into_iter()`）则取走所有权。
- **`copied()`**：把 `&T` 迭代器变成 `T` 迭代器——对每个元素做**位拷贝**（`*v`）；要求 `T: Copy`（`i32` 等），零开销；等价 `iter().map(|&v| v)`。
- **`cloned()`**：把 `&T` 迭代器变成 `T` 迭代器——对每个元素调用 `clone()`（`v.clone()`）；要求 `T: Clone`（`String`/`Vec` 等深拷贝类型）；等价 `iter().map(|v| v.clone())`。**选型**：`T: Copy` 时优先 `copied()`（明确、零开销）；只有 `Clone` 无 `Copy` 时才用 `cloned()`。

```rust
let twice_vs: Vec<_> = vs.iter().map(|x| x * 2).collect();
let evens: Vec<_> = vs.iter().filter(|x| **x % 2 == 0).collect();
for (i, x) in vs.iter().enumerate() {
    println!("v[{i}] = {x}");
}
let merged: Vec<_> = vs.iter().chain([5, 6].iter()).collect(); // 首尾拼接
let nums: Vec<i32> = vs.iter().copied().collect();            // &i32 → i32，位拷贝
let ss = vec![String::from("a"), String::from("b")];
let strs: Vec<String> = ss.iter().cloned().collect();          // &String → String，深拷贝
```

## 自动测试 (Automated Testing)

> 定位并修复一个问题的代价正比于代码规模的**平方**（规模代价平方定律）——所以越早、越小范围地发现并修复错误越好。单元测试是最小单位（模块）的正确性检验，Rust 内置支持。

### 测试函数与断言

**定义：** 用 `#[test]` 标注测试函数；函数内用断言检查行为是否符合预期：

```rust
#[test]
fn it_works() {
    let result = 2 + 2;
    assert_eq!(result, 4);
}
```

- `assert!(cond)`：断言一个值一定是 `true`。
- `assert_eq!(a, b)`：断言两个值一定相等。
- `Option::unwrap`/`expect`：断言一个 `Option` 一定是 `Some`。

**注意**：测试函数中出现的**恐慌会被捕捉**下来并标记该测试失败，而不会退出程序。

### 运行测试

```bash
$ cargo test
running 1 test
test tests::it_works ... ok
test result: ok. 1 passed; 0 failed; 0 ignored; 0 measured; 0 filtered out;
```

它会汇报每个测试的结果，并给出所有测试通过情况的统计。

### 测试的组织

- **同文件**：通常把单元测试与被测代码放在同一个文件；养成"每写一个函数，就在同一个文件中实现对它的单元测试"的习惯。
- **子模块 + 条件编译**：想让测试代码仅在测试模式下编译（不拖累正常编译时间），用 `#[cfg(test)]` 包住 `mod tests`：

```rust
#[cfg(test)]
mod tests {
    use super::vector_length;

    #[test]
    fn test_vector_length() {
        assert_eq!(vector_length(&vec![1, 2, 3]), 3);
    }
}
```

### 测试选项

- `cargo test -- --test-threads=1`：串行运行（默认并行；测试同时运行可能出错时用）。
- `cargo test test_2`：只运行名字含 `test_2` 的单个测试。

## 小结

- **字符串**：UTF-8 编码；`String`（拥有、堆上、可增长）与 `&str`（借用、切片）；不能按字节下标，用 `chars()`。
- **Option**：用"有值或空"取代魔法空值，配 `unwrap`/`expect`/`map`/`and_then`/`unwrap_or` 等组合子。
- **错误处理**：可恢复用 `Result` + `?`，不可恢复用 `panic!`；判断标准是"是否进入坏状态"。
- **容器与迭代器**：按复杂度/有序性选型；迭代器统一"遍历 + 适配 + 汇聚"，配 `collect`/`fold`/`map`/`filter` 等。
- **自动测试**：`#[test]` + `cargo test`，断言驱动。
