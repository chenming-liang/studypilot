## Rust 语言介绍

Rust 是一门以**构建可靠且高效的软件**为目标的系统编程语言。

- **高效 (performance)**：没有运行时和垃圾收集器，代码的运行速度快、内存使用效率高，可用来开发对性能要求高的服务。
- **可靠 (reliability)**：用**类型系统 (type system)** 和**所有权模型 (ownership model)** 在编译时消除内存安全性与线程安全性的隐患。
- **好用 (productivity)**：有丰富的文档、友好的编译器（提供有用的错误信息）和一流的工具集，包括集成的包管理器和构建工具、支持各种编辑器的代码自动补全和类型查看功能、代码自动格式化工具等。

**使用场景**：命令行工具、网页应用、网络服务、嵌入式开发。

**发展历史**（择要）：

- 2006 年由 Graydon Hoare 作为个人项目首次出现，2010 年成为 Mozilla 官方项目，2015 年 5 月 16 日发布 1.0.0。
- 2021 年 2 月 8 日，AWS、华为、Google、微软与 Mozilla 成立 **Rust 基金会**。
- 2025 年 2 月 20 日 Rust 1.85.0 发布，**Rust 2024 版本 (edition)** 正式启用。

**用 Rust 编写的软件**：Rust 语言工具链、Redox 操作系统、Linux 6.1 内核的 Rust 支持、Servo 浏览器引擎、Typst 排版系统、lsd/bat/fd 等命令行工具、rCore 教学操作系统、MadFS 文件系统等。

## 第一个程序：Hello, Rust!

用 Rust 编写"Hello, world!"程序，体会**编译与运行**的基本流程：

```rust
fn main() {
    println!("Hello, world!");
}
```

```bash
$ rustc hello.rs
$ ./hello
Hello, world!
```

这里涉及的知识点：**函数定义**（`fn`）、**`main` 函数**（程序入口）、**输出（宏调用）**、**字符串**、**编译与运行**。

**项目管理：Cargo**。用 Cargo 创建并运行一个项目：

```bash
$ cargo new guessing_game   # 创建项目
$ cd guessing_game
$ cargo run                 # 编译并运行（仅编译用 cargo build）
```

`Cargo.toml`（**TOML (Tom's Obvious, Minimal Language)** 是一种配置文件格式）声明项目元数据与依赖：

```toml
[package]
name = "guessing_game"
version = "0.1.0"
edition = "2024"

[dependencies]
```

**注意**：`cargo run` 自动编译并运行、便于快速迭代；`cargo build` 只编译。

## 变量绑定 (Variable Binding)

> 变量是程序状态的基本载体；Rust 用"绑定"而非"赋值"，以强调所有权与不可变性。

**定义：** 使用 `let` 把值**绑定**到一个名字上。默认绑定是**不可变的 (immutable)**，用 `mut` 修饰后可**可变 (mutable)**：

```rust
let x = 17;      // 类型由编译器推断，此处为 i32
let x: i16 = 17; // 也可显式指定类型

let y = 5;
y += 1;  // 错误：不可变变量 y 被重新赋值

let mut z = 5;
z += 1;  // OK!
```

- 编译器不一定总能成功推断类型（或推断结果不是用户想要的），此时可**显式标注**类型 `let x: i16 = 17`。
- **注意**：可变性是**绑定**的属性，不是值的属性——同一个值，通过**可变绑定**访问就能改，通过**不可变绑定**访问就不能改。可变性由访问它的"入口"决定，而非值本身：
  ```rust
  let v = vec![1, 2, 3];
  v.push(4);            // 错误：绑定 v 不可变，不能经它修改
  let mut w = vec![1, 2, 3];
  w.push(4);            // OK!
  ```
  三个推论：
  - **结构体字段不能标 `mut`**：`struct P { mut y: i32 }` 非法——可变成员的做法是 `let mut p = P { .. }; p.y = 5;`，可变性从绑定传递到字段；
  - **掩盖可建立新的可变绑定**：`let mut x = x;` 把旧绑定遮住、新绑定可变（掩盖是建立新绑定，`mut` 是就地修改，见下节）；
  - **可变引用 `&mut T` 要求被借对象本身是 `mut` 绑定**：可变访问需要独占权，这正是第 2 讲"同一时刻仅有一个可变引用"规则的由来。

**掩盖 (Shadowing)**：可以用同名新绑定"遮住"旧绑定，旧绑定在当前作用域 (scope) 内失效：

```rust
let x = 17;
let x = "Shadowed!";   // x 不可变，但可以重新绑定
let mut cost = String::new();
let cost: f64 = cost.trim().parse().unwrap(); // 同名不同型
```

- **注意**：掩盖与 `mut` 不同——`mut` 就地修改同一个值，掩盖是建立**新绑定**。

**常量 (Constants)**：`const` 声明**编译时常数**，与不可变变量不同——在编译时可确定、可出现在任何作用域（含全局）、可提前使用：

```rust
const PI: f64 = 3.14159;
const MAGIC: i32 = 42;
```

## 表达式 (Expressions)

> Rust 是"表达式语言"：几乎一切都产生值，这让代码更紧凑、更函数式。

**定义：** **表达式 (expression)** 是会产生一个值 (value) 的代码片段；**几乎所有东西都是表达式**，例外是**变量绑定**。

**单位元 (unit) 类型** `()` 表示"空"，只有一个取值 `()`，是**默认的返回类型**：

```rust
fn foo() -> i32 { 5 }
fn bar() -> () { () }
fn baz() -> () { 5; }
fn qux()       { 5; }
```

- 表达式后加分号 `;` 会**舍弃它的值**，结果变为 `()`——因此以分号结尾的函数返回 `()`。
- **示例：** `if`、`loop` 作为表达式可以绑定到变量：

```rust
let y = if x > 0 { "greater" } else { "less" };

let z = loop {
  x += 10;
  if x > 5 { break x; }  // break 携带返回值
};
```

## 基本类型 (Basic Types)

> 数据类型的分类决定"能存什么、占多大、怎么操作"；Rust 把这些信息显式写进类型系统。

**定义：** 基本类型分三类：

- **布尔 (bool)**：`true`/`false`。
- **字符 (char)**：单引号，例如 `'R'`、`'计'`，是 Unicode 的。
- **数值**：整数与浮点。
  - 有符号整数 `i8 i16 i32 i64 i128 isize`；无符号整数 `u8 u16 u32 u64 u128 usize`。
  - 浮点 `f32`、`f64`。
  - **注意**：`isize`/`usize` 是**指针大小**的整数，大小与机器架构相关。

**字面值 (literals)**：写为 `10i8`、`10u16`、`10.0f32`、`10usize` 等形式；不指定类型且未被推断时，默认整数为 `i32`、浮点为 `f64`。

**类型转换 (cast)**：用 `as` 在**可以安全转换**的类型之间转换：

```rust
let x: i32 = 100;
let y: u32 = x as u32;
```

- **注意**：并非所有类型都能安全转换——`[u8; 4]` 不能转成 `char`；不安全的机制会牺牲编译器的安全性保证。

## 集合类型 (Collections)

> 一个变量常需要容纳多个值；Rust 提供定长数组与动态集合。

### 数组 (Array)

**定义：** 数组类型写作 `[T; N]`，`N` 是**编译时常数**，因此长度固定；运行时按 `[]` 下标访问（从 0 开始）并**检查越界**：

```rust
let arr1 = [1, 2, 3]; // 3 个元素的数组
let arr2 = [2; 32];   // 32 个 2
```

### 切片 (Slice)

**定义：** 切片类型写作 `&[T]`，是**引用序列中一部分的视图**；不能直接创建，需从别的变量**借用 (borrow)**：

```rust
let arr = [0, 1, 2, 3, 4, 5];
let total_slice = &arr[..];     // 整个 arr
let partial_slice = &arr[2..5]; // [2, 3, 4]
```

- 切片可以是可变的，也可以是不可变的；其有效性由所有权保证（下一讲）。

### 字符串 (String)

**定义：** Rust 有两种字符串——堆上可增长的 `String`，和它的切片 `&str`；形如 `"foo"` 的**字符串字面值**都是 `&str`：

```rust
let s: &str = "galaxy";
let s2: String = "galaxy".to_string();
let s3: String = String::from("galaxy");
let s4: &str = &s3;
```

- **注意**：`str` 是没有大小的类型（编译时不知大小），无法独立存在，只能以 `&str` 引用。

### 元组 (Tuple)

**定义：** 元组是**固定大小**、**有序**、**异构**的列表；用下标 `foo.0` 访问分量，也可用 `let` 绑定**解构 (destructure)**：

```rust
let foo: (i32, char, f64) = (72, 'H', 5.1);
let (a, b, c) = foo; // a = 72, b = 'H', c = 5.1
```

### 向量 (Vector)

**定义：** `Vec<T>` 是分配在**堆上**、可**增长**的数组，类似 C++ 的 `std::vector`、Java 的 `ArrayList`；`<T>` 是**泛型 (generics)**，如 `Vec<i32>`。用 `Vec::new()` 或 `vec!` 宏创建：

```rust
let v0: Vec<i32> = Vec::new();
let mut v1 = Vec::new();
v1.push(1);
let v2 = vec![1, 2, 3];
let v3 = vec![0; 4];
```

- **注意**：下标必须用 `usize` 类型——不能用 `i32` 等作下标，需 `i as usize` 显式转换：

```rust
let i: i8 = 2;
let y = v2[i as usize];
```

## 引用 (References)

> 为避免拷贝，需要"借用"数据——引用即编译期保证合法的借用指针。

**定义：** 在类型前写 `&` 表示**引用类型** `&i32`；用 `&` 取引用、`*` 解引用（类似 C++）：

```rust
let x = 12;
let ref_x = &x;
println!("{}", *ref_x); // 12
```

- **注意**：Rust 中**引用保证是合法的**——合法性通过**编译时检查**；因此引用和一般意义的指针不一样。
- 引用的**生命周期**较复杂，下一讲会详细讨论。

## 控制流 (Control Flow)

> 顺序、条件、循环构成程序骨架；Rust 中这些结构大多是表达式。

### 条件语句 (if)

**定义：** `if` 是**表达式**，每个分支必须是**相同类型**；与 C++ 不同，条件**不需要小括号**：

```rust
if x > 0 {
    10
} else if x == 0 {
    0
} else {
    println!("Not greater than zero!");
    -10
}
```

- 若只想作为普通语句使用，令分支结果类型为 `()` 即可：

```rust
if x <= 0 {
    println!("Too small!");
}
```

### 循环 (while / loop / for)

**定义：** Rust 有三种循环；`break`/`continue` 控制流程：

- `while`：条件循环，用法与 C++ 相同（条件不括小括号）。
- `loop`：相当于 `while true`；其 `break` 可以**返回一个值**作为整个循环的结果（另外两种没有此功能）。
- `for`：类似 C++ 的范围循环，遍历**迭代器 (iterator)**；`n..m` 是半闭半开区间、`n..=m` 是闭区间。

```rust
let mut x = 0;
while x < 100 { x += 1; }

let y = loop {
    x += 1;
    if x * x >= 100 { break x; }
};

for i in 0..10 { println!("{}", i); }
for v in &xs { println!("{}", v); } // 数组/切片/向量都可作迭代器
```

### 跳出多层循环 (Labels)

**定义：** 用 `'label:` 给循环命名，用 `break 'label` 跳出**多层**循环：

```rust
let mut sum = 0;
'outer: for i in 1..10 {
    for j in 1..10 {
        sum += i * j;
        if sum > 1000 { break 'outer; }
    }
}
println!("sum = {sum}");
```

## 模式匹配 (Pattern Matching)

> 相比 if-else 链，`match` 让"多分支 + 解构 + 绑定"一次完成。

**定义：** 匹配语句由**一个表达式**和一组 `值 => 表达式` 的分支组成，整个 `match` 是**表达式**，所有分支类型必须一致；`_` 捕捉**所有情况**：

```rust
let x = 3;
match x {
    1 => println!("one fish"),      // 逗号必须写
    2 => { println!("two fish"); }, // 花括号时逗号可省略
    _ => println!("no fish for you"),
}
```

**模式 (patterns)** 可以是任意复杂表达式（元组、函数调用），可绑定变量、可用 `if` 加**匹配守卫 (match guard)**：

```rust
match (x, y) {
    (1, 1) => println!("one"),
    (2, j) => println!("two, {}", j),
    (i, j) if i > 5 && j < 0 => println!("On guard!"),
    _ => println!(":<"),
}
```

- **注意**：匹配模式必须**穷尽**（覆盖所有可能）才能编译通过；`_` 用于忽略不需要的部分。
- 模式也可用于 `let` 绑定（**模式绑定**）：`let (a, b) = ("foo", 12);`。

## 函数 (Functions)

> 函数把逻辑封装成可复用单元；Rust 要求显式类型，强调意图清晰。

**定义：** 用 `fn` 定义函数；参数与返回值类型**必须显式标注**——设计者认为显式指定是更好的实践，尽管编译器本可推断：

```rust
fn foo(x: T, y: U, z: V) -> T { // ... }
```

**返回规则**：函数的**最后一个表达式**是返回值；`return` 可提前返回：

```rust
fn square(n: i32) -> i32 { n * n }
fn squareish(n: i32) -> i32 {
    if n < 5 { return n; }
    n * n
}
```

- **注意**：`n * n;` 以分号结尾会**舍弃值**、返回 `()`，与声明的 `-> i32` 不符，无法编译。

## 宏与调试工具 (Macros & Debugging)

> 宏在编译期生成代码，是 Rust 代码生成的主要手段；标准库提供了大量输出与调试宏。

### 宏 (Macro)

**定义：** 宏看起来像函数，但**名字以 `!` 结尾**，原理是**在编译时产生代码**；可自定义，很多常用工具由宏实现。

### 输出宏：print! / println! / format! / dbg!

- `print!`/`println!`：输出文字；`{}` 字符串插入、`{:?}` 调试输出；`{}` 内可写参数序号或**变量名**：

```rust
print!("{}, {}, {}", x, 3, true);      // => foo, 3, true
println!("{:?}, {:?}", x, [1, 2, 3]);  // => "foo", [1, 2, 3]
println!("{0}, {y}, {0}", x);          // => foo, 1, foo
```

- `format!`：以同样的格式化语法**返回 `String`**（不输出）。
- `dbg!`：打印变量/表达式值用于调试，且自身是表达式、值即内部表达式值：

```rust
let y = dbg!(x * 2) + 3;
```

```text
[src/main.rs:3:13] x * 2 = 4
[src/main.rs:4:5] y = 7
```

### 错误处理与占位宏

- **`panic!`（恐慌 (panic)）**：显示提示信息并**退出当前任务**——一种不优雅的错误处理方式，有更好方案时不要用：

```rust
if x < 0 { panic!("Kaboom!"); }
```

- **`assert!`/`assert_eq!`**：条件不成立（或左右不等）即恐慌，常用于**测试**与捕捉非法条件：

```rust
#[test]
fn test_something() {
    let actual = 1 + 2;
    assert!(actual == 3);
    assert_eq!(3, actual);
}
```

- **`unreachable!`**：表示**不会到达**的分支，运行到即恐慌，用于追踪意外问题。
- **`unimplemented!`/`todo!`**：`panic!("not implemented")` 的简写，标注**未实现**的功能；`todo!` 传达"以后会实现"而 `unimplemented!` 没有。

## 注释与代码风格 (Comments & Style)

> 注释解释"为什么"，代码风格让团队可读；Rust 社区有明确惯例。

**注释 (comments)**：块注释 `/* ... */` 与行注释 `// ...`；三个 `/` 的 `///` 是**文档字符串注释 (docstring)**，`rustdoc` 用它生成文档并支持 Markdown：

```rust
/// Triple-slash comments are docstring comments.
fn foo() {
    // Double-slash comments are normal.
    /* Block comments also exist and can be nested! */
}
```

**命名规范**：

- 大驼峰 (UpperCamelCase)：类型名、特型名。
- 蛇形 (snake_case)：变量、函数、模块、宏名。
- 大写蛇形 (SCREAMING_SNAKE_CASE)：常量、静态变量名。

**缩进与空白**：缩进 4 空格；操作符前后各一空格（`x + 1`）；分隔符后一空格（`f(x, 1)`）。

**注释之道**：写有意义的注释；写文档注释（`///`、`//!`）；尽量用英文写注释。

## 综合示例：猜数游戏

> 把本讲的概念串起来：程序随机生成 1–100 的秘密整数 $n$，用户反复猜 $x$，直到猜中。

**要求**：若 $x = n$ 打印祝贺并退出；否则按 $x$ 与 $n$ 的大小关系提示，继续让用户猜。

**生成秘密数**：先在 `Cargo.toml` 加入外部依赖 rand 包：

```toml
[dependencies]
rand = "0.10.2"
```

```rust
use rand::RngExt;
use std::cmp::Ordering;

let secret_number = rand::rng().random_range(1..=100);
```

**读取输入并解析**：`String::new()` + `io::stdin().read_line` 读入，`trim().parse()` 转成 `u32`；`parse()` 返回 `Result`，用 `match` 取出成功值、失败则 `continue`：

```rust
use std::io;

let mut guess = String::new();
io::stdin()
    .read_line(&mut guess)
    .expect("Failed to read line");

let guess: u32 = match guess.trim().parse() {
    Ok(num) => num,
    Err(_) => continue,   // 解析失败，跳过本轮
};
```

**比较与循环**：`guess.cmp(&secret_number)` 产生 `Ordering`（`Less`/`Greater`/`Equal`），用 `match` 输出提示；猜中时 `break` 退出 `loop`：

```rust
loop {
    // ...
    match guess.cmp(&secret_number) {
        Ordering::Less => println!("Too small!"),
        Ordering::Greater => println!("Too big!"),
        Ordering::Equal => { println!("You win!"); break; }
    }
}
```

这个示例综合运用了：`use` 引入模块、可变 `String`、`read_line` 读输入、`.expect()` 错误处理、`parse()` + `match` 类型转换、`match` 匹配 `Ordering`、`loop` + `break`/`continue`。
